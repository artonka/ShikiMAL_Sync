# Shiki → MAL Sync

Пользовательский скрипт для автоматической односторонней синхронизации списков **Shikimori → MyAnimeList**. Работает на страницах тайтлов (аниме, манга, ранобэ): отслеживает изменения и мгновенно отправляет их в официальный API MyAnimeList.

## Возможности

* **Полная поддержка форматов:** синхронизирует аниме, мангу и ранобэ.
* **Перенос всех ключевых данных:**
  * Статус (`Запланировано`, `Смотрю/Читаю`, `Просмотрено/Прочитано`, `Отложено`, `Брошено`).
  * Прогресс (эпизоды, главы, тома).
  * Оценка.
  * Количество пересмотров/перечитываний.
  * Заметки.
* **Мгновенная реакция:** Синхронизация сразу после клика по `+1` или смены статуса + фоновый опрос каждые 15 секунд.
* **Работа с ID:** по умолчанию берёт ID из URL страницы. Если ID на Шикимори и MAL не совпадают, можно привязать нужный MAL ID вручную кнопкой `ID`.
* **Двусторонняя навигация:** добавляет кнопку перехода на страницу тайтла в MAL, а на самом MyAnimeList — плавающую кнопку `← На Шикимори`.
* **Адаптивный дизайн:** 
  * Панель управления встраивается под постер тайтла.
  * Подстраивание под кастомную тему [E-design](https://shikimori.io/clubs/1678-e-club-podderzhka-stilya-edesign-dlya-shikimori).

## Установка и настройка

### 1. Установка скрипта
1. Установите менеджер пользовательских скриптов: **Tampermonkey** или **Violentmonkey**.
2. В расширении выберите `Создать новый скрипт`.
3. Сотрите весь текст, вставьте код из `script.js` и сохраните. 

### 2. Получение Client ID на MyAnimeList

1. Перейдите в настройки API вашего профиля MAL: https://myanimelist.net/apiconfig.
2. Заполните поля:
   * **App Type:** укажите строго `other`.
   * **App Redirect URL:** укажите строго `https://myanimelist.net/`.
   * Остальные поля заполните на своё усмотрение и сохраните.
3. Откройте созданное приложение и скопируйте **Client ID**.

### 3. Авторизация
1. Откройте любую страницу аниме, манги или ранобэ на Шикимори.
2. Под обложкой появится панель скрипта — нажмите **«Синхронизировать»**.
3. Вставьте скопированный **Client ID** во всплывающее окно.
4. В открывшемся окне MyAnimeList нажмите **Allow** — токен сохранится автоматически, и окно закроется.

##  Как пользоваться

Панель под постером состоит из трёх элементов и строки состояния:

* **`[ Синхронизировать ]`** — главная кнопка. Принудительно отправляет текущее состояние тайтла с Шикимори на MAL. На ней же отображается иконка текущего статуса (наведите курсор на иконку, чтобы увидеть подробности и время последней отправки):
  * 🟢 **Галочка (`ok`)** — списки полностью синхронизированы.
  * 🟡 **Восклицательный знак (`warn`)** — данные на MAL отличаются от Шикимори (при первом открытии); запись была удалена на Шикимори или MAL не принял часть данных. Нажмите на кнопку, чтобы применить изменения.
  * 🔴 **Крестик (`error`)** — ошибка сети; требуется повторная авторизация.
* **`[ ↗ ]`** — открывает страницу этого тайтла на MyAnimeList в новой вкладке.
* **`[ ID ]`** — позволяет вручную задать MAL ID для текущего тайтла, если идентификаторы на сайтах не совпадают (оставьте поле пустым для сброса).
* **Строка статуса снизу** — показывает текущие данные тайтла напрямую с сервера MAL.

### Сброс авторизации
Если нужно сменить аккаунт или **Client ID**, откройте меню расширения на вкладке Шикимори и выберите пункт **«MAL Sync: сбросить вход (Client ID и токен)»**.
